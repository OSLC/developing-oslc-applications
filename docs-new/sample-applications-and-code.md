## Sample applications

Having done the [tutorials](./tutorials.md), if you'd like to explore some existing code, there are a variety of samples and existing applications available to be inspired from.

!!! success "Start here"

    Start with the [OSLC Reference Implementation](https://github.com/oslc-op/refimpl) for a set of examples of:
 
    - how to implement OSLC Requirements Management domain
    - how to implement OSLC Change Management domain
    - how to implement OSLC Quality Management domain
    - how to implement OSLC Architecture Management domain
    - how to model and generate Jakarta REST code for 4 OSLC servers using an MBSE approach using Lyo Designer
    - how to use Lyo Client to write a Kotlin-based client populating the 4 OSLC servers 
 
!!! success "Jazz samples"
    Start with [Lyo Client sample code](https://github.com/OSLC/lyo-samples) for:
    
    - examples of using Jazz OSLC API through Lyo
    - tools to get started with discovery and OAuth support in Lyo

!!! tip
    Lyo maintains [a list](https://github.com/eclipse-lyo/lyo#test-and-sample-repositories) of open-source projects using Lyo along with the version of Lyo targeted. Also, an instance of the [Sourcebot](https://oslc-sourcebot.berezovskyi.me/~/repos) code search appliance is set up against many OSLC-related open-source repos (114 and counting as of 2025-07). 

* The [iotp-adaptor](./iotp_adaptor/index.md) is an OSLC adapter for IBM Watson IoT Platform. This sample provides a thorough user guide, as well as a developer guide covering many topics such as authentication, TRS, using [Lyo Designer](./eclipse_lyo/eclipse-lyo.md#lyo-designer), etc.
* [danlz/lyo-in-spring-boot](https://github.com/danlz/lyo-in-spring-boot) is a sample application demonstrating the use of Lyo with Spring Boot.
* [Simulink](https://wiki.eclipse.org/Lyo/Simulink)
* [MagicDraw](https://wiki.eclipse.org/Lyo/MagicDraw)

The [OSLC4Net](https://github.com/OSLC/oslc4net) project includes sample applications if you favor .NET/C#.
