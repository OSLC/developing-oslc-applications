# Contributing to Eclipse Lyo

Use the [Lyo repository](https://github.com/eclipse-lyo/lyo) for SDK source code, issues and pull requests.

- [Report a Lyo issue](https://github.com/eclipse-lyo/lyo/issues/new).
- [Review open pull requests](https://github.com/eclipse-lyo/lyo/pulls).
- [Release the Java SDK](release-process.md).
- [Prepare a dependency inventory](dependency-review.md).
- [Use the Lyo client](lyo-client.md).
- [Find OSLC documentation](documentation-sites.md).

For changes between SDK versions, use the [migration guides](migration-overview.md).
