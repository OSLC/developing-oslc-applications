# OSLC documentation sites

Use these entry points when publishing or looking for OSLC content:

| Content | Location |
| --- | --- |
| Community information and resources | [open-services.net](https://open-services.net/) |
| Developer guides and tutorials | [OSLC Developer Guide](https://oslc.github.io/developing-oslc-applications/) |
| Lyo SDK source, issues and release notes | [eclipse-lyo/lyo](https://github.com/eclipse-lyo/lyo) |
| Lyo Designer source and issues | [eclipse-lyo/lyo.designer](https://github.com/eclipse-lyo/lyo.designer) |
| OSLC specifications and open project work | [OASIS OSLC Open Project](https://github.com/oslc-op) |
| Older community material | [open-services.net archive](https://archive.open-services.net/) |

Keep repository README files focused on the repository’s purpose, setup and links to its maintained guides.
Publish user guides in the developer guide and use issues and pull requests for development discussions.

When moving a page, retain its original address and add a notice linking to the maintained destination after deployment.
The previous page contained an earlier reorganisation proposal; its technology descriptions and task lists no longer describe this guide.
